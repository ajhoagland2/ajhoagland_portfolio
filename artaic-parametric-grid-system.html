01 / Parametric Design Platform

PARAMETRIC GRID GENERATION PLATFORM

An Onshape design automation framework using variables, configurations, and rule-based modeling to generate repeatable manufacturing-ready grid variants.

Senior Systems Case Study

FROM REPETITIVE CAD WORK TO CONFIGURABLE DESIGN PLATFORM

Problem

Generating new mosaic grid configurations required repetitive CAD work and specialized knowledge to maintain compatibility with manufacturing requirements. As product variations increased, the manual workflow became difficult to maintain and scale.

Constraints

The platform needed to support hundreds of possible configuration combinations, preserve strict manufacturing rules, generate repeatable outputs, and support future product variations without rebuilding models from scratch.

Solution

Developed a parametric design framework inside Onshape using Variables, Configurations, and rule-based modeling practices. The system transformed grid generation from a manual CAD task into a configurable process driven by predefined inputs.

Results

Standardized the generation of grid variants, reduced repetitive modeling effort, improved design consistency, and enabled faster development of new product configurations.

Value Created

Increased engineering efficiency, created a scalable framework for large configuration sets, embedded design intent into the model for knowledge transfer, and established a reusable digital asset for future manufacturing and product development initiatives.

Dimensional Validation

GRID DIMENSIONAL ACCURACY

Printed grid samples were measured with a micrometer and compared against their nominal dimensions. The exported analysis summarizes average dimensional error by grid and checks each result against a ±0.30% process window.

Square grid analysis

The comparison places every measured grid on one error scale, making drift and outliers visible while preserving the source measurements in the static report.

Formulas used Actual in = (1 × whole) + (0.1 × tenths) + (0.01 × hundredths) + (0.001 × thousandths) Actual mm = Actual in × 25.4 Error % = ((Actual mm − Expected mm) ÷ Expected mm) × 100 Grid error % = mean of the four point-error percentages

Non-square grid analysis

Rectangular variants are evaluated by width and height independently before the axis results are reviewed together. This keeps directional error visible instead of reducing a non-square grid to one nominal dimension.

Formulas used X error % = ((Measured X − Expected X) ÷ Expected X) × 100 Y error % = ((Measured Y − Expected Y) ÷ Expected Y) × 100 Diagonal error = mean(|Measured diagonal − Expected diagonal|)
